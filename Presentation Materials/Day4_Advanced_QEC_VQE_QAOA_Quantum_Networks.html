🌊 1. Quantum Noise — A Formal Treatment

Quantum noise describes unintended interactions between a quantum system and its environment. Unlike classical bit-flip errors, quantum errors are continuous — they can corrupt both amplitude (magnitude) and phase of quantum states.

1.1 Quantum Error Types

Error TypeMathematical FormPhysical Cause
Bit-flip (X error)ρ → XρX†Energy relaxation: |1⟩ decays to |0⟩
Phase-flip (Z error)ρ → ZρZ†Dephasing: random Z rotations from environment
Bit+Phase (Y error)ρ → YρY† = iXZ|ψ⟩Combined energy+dephasing
Depolarisingρ → (1-p)ρ + p/3(XρX+YρY+ZρZ)Generic symmetric noise
Amplitude dampingKraus operators K₀,K₁ for T1Spontaneous emission (|1⟩→|0⟩)
Phase dampingKraus operators for T2Random phase kicks (decoherence)

1.2 Simulating Noise with Qiskit Aer

from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator
from qiskit_aer.noise import (NoiseModel, depolarizing_error,
                               thermal_relaxation_error, ReadoutError)
import numpy as np

# Build a realistic IBM-like noise model
noise_model = NoiseModel()

# 1-qubit gate errors (depolarising)
error_1q = depolarizing_error(0.001, 1)  # 0.1% depolarising
noise_model.add_all_qubit_quantum_error(error_1q, ['u1', 'u2', 'u3', 'sx', 'x'])

# 2-qubit gate errors (higher error rate)
error_2q = depolarizing_error(0.005, 2)  # 0.5% depolarising on CNOT
noise_model.add_all_qubit_quantum_error(error_2q, ['cx', 'ecr'])

# T1/T2 thermal relaxation (assuming 200µs T1, 150µs T2, gate time 50ns)
t1, t2, gate_time = 200e3, 150e3, 50  # ns units
thermal_error = thermal_relaxation_error(t1, t2, gate_time)
noise_model.add_all_qubit_quantum_error(thermal_error, ['sx', 'x'])

# Readout error matrix [[P(0|0), P(1|0)], [P(0|1), P(1|1)]]
readout_error = ReadoutError([[0.985, 0.015], [0.020, 0.980]])
noise_model.add_all_qubit_readout_error(readout_error)

# Run noisy simulation
qc = QuantumCircuit(2, 2)
qc.h(0); qc.cx(0, 1); qc.measure([0,1],[0,1])

sim_noisy = AerSimulator(noise_model=noise_model)
result = sim_noisy.run(transpile(qc, sim_noisy), shots=4096).result()
counts = result.get_counts()
print("Noisy Bell state:", counts)
# Ideal: {'00':~2048, '11':~2048}. Noise adds '01' and '10' counts

🛡 2. Quantum Error Correction — Foundations

QEC solves what seemed impossible: protecting quantum information from noise without violating the no-cloning theorem. The key insight (Shor 1995, Steane 1996) is that you don't need to copy the qubit — you can spread entanglement across many physical qubits so errors on individual qubits can be detected and corrected by measuring syndromes without collapsing the logical qubit.

2.1 The Three Pillars of QEC

  1. Redundancy — Encode 1 logical qubit in N physical qubits (overhead)
  2. Syndrome measurement — Measure error syndromes (parity checks) without measuring the logical qubit itself
  3. Correction — Apply recovery operations based on syndrome measurement outcome

2.2 The 3-Qubit Bit-Flip Code (Simplest QEC)

|0⟩_L = |000⟩ |1⟩_L = |111⟩

Encode: |ψ⟩ = α|0⟩+β|1⟩ → α|000⟩+β|111⟩ using 2 CNOT gates

Error: if qubit 1 flips → α|010⟩+β|101⟩

Syndrome: measure Z₀Z₁ and Z₁Z₂ → (−1, +1) → qubit 1 flipped → apply X₁

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

def encode_bit_flip(qc, data, ancillas):
    """Encode logical |ψ⟩ into 3-qubit bit-flip code."""
    qc.cx(data, ancillas[0])
    qc.cx(data, ancillas[1])
    return qc

def syndrome_measurement(qc, data_qubits, syndrome_qubits):
    """Measure Z₀Z₁ and Z₁Z₂ syndromes without disturbing logical qubit."""
    qc.cx(data_qubits[0], syndrome_qubits[0])
    qc.cx(data_qubits[1], syndrome_qubits[0])
    qc.cx(data_qubits[1], syndrome_qubits[1])
    qc.cx(data_qubits[2], syndrome_qubits[1])
    return qc

# Full 3-qubit code circuit
from qiskit import ClassicalRegister, QuantumRegister
data = QuantumRegister(3, 'data')
syndrome = QuantumRegister(2, 'syndrome')
c_syn = ClassicalRegister(2, 'c_syn')
c_out = ClassicalRegister(3, 'c_out')
qc = QuantumCircuit(data, syndrome, c_syn, c_out)

# Prepare logical |+⟩ = (|0⟩+|1⟩)/√2
qc.h(data[0])
qc.barrier()

# Encode into logical qubit
encode_bit_flip(qc, data[0], [data[1], data[2]])
qc.barrier()

# Inject error on qubit 1 (simulating a bit-flip)
qc.x(data[1])
qc.barrier()

# Measure syndromes
syndrome_measurement(qc, [data[0], data[1], data[2]], [syndrome[0], syndrome[1]])
qc.measure(syndrome, c_syn)
qc.barrier()

# Conditional correction based on syndromes (classically controlled)
# Syndrome '01' → qubit 2 flipped; '10' → qubit 0 flipped; '11' → qubit 1 flipped
# (Simplified — use if_test in real dynamic circuit)
qc.x(data[1])  # Correct the injected error

qc.measure(data, c_out)
sim = AerSimulator()
result = sim.run(qc, shots=1024).result()
print("Corrected output:", result.get_counts())

🔷 3. Stabiliser Codes — Shor, Steane & Surface Codes

3.1 The Shor Code (9 Physical Qubits)

Peter Shor's 1995 code was the first to correct all single-qubit errors by combining the 3-qubit bit-flip code and 3-qubit phase-flip code:

|0⟩_L = (|000⟩+|111⟩)⊗³ / 2√2
|1⟩_L = (|000⟩−|111⟩)⊗³ / 2√2

The Shor code uses 9 physical qubits to encode 1 logical qubit — distance 3 code that corrects any single-qubit error.

3.2 The Steane [[7,1,3]] Code

The Steane code (1996) uses just 7 physical qubits to protect 1 logical qubit and correct any single-qubit error. It is a CSS (Calderbank-Shor-Steane) code built from the classical [7,4] Hamming code.

3-qubit bit-flip[[3,1,1]]3Bit-flip only
Shor code[[9,1,3]]9Any single-qubit error
Steane code[[7,1,3]]7Any single-qubit error
Surface code d=5[[25,1,5]]25Any 2-qubit error
Surface code d=7[[49,1,7]]49Any 3-qubit error

📐 4. The Surface Code — IBM's Path to Fault Tolerance

The toric/surface code (Kitaev 1997, Fowler et al. 2012) is the leading candidate for fault-tolerant quantum computing. It arranges qubits on a 2D grid and uses local stabiliser measurements (only nearest-neighbour interactions) — compatible with the heavy-hex lattice.

4.1 Surface Code Key Properties

  • Distance d: A d×d grid encodes 1 logical qubit in d² physical qubits, corrects ⌊(d-1)/2⌋ errors
  • Threshold: Logical error rate drops exponentially once physical error rate < ~1% (threshold)
  • CNOT count: Each syndrome cycle requires 4 CNOTs per stabiliser measurement — minimal for 2D local code
  • Overhead: ~1,000 physical qubits per logical qubit for target logical error rate of 10⁻¹⁰
P_logical ≈ A · (p/p_th)^⌈d/2⌉ where p = physical error rate, p_th ≈ 1%

4.2 IBM Quantum QEC Experiments

  • 2023: IBM demonstrated a distance-3 [[7,1,3]] code on Eagle processor, observing exponential suppression of logical error rate with code distance
  • 2024: Heron r2 demonstrations showed distance-5 surface code with logical error rates below physical error rates — "break-even" achieved
  • 2025 target: Distance-7 code with logical error rate <10⁻⁶
  • 2033 target: 100 logical qubits at 10⁻¹⁰ error rate for fault-tolerant applications
# Simulating a basic repetition code (classical analogue of surface code)
from qiskit import QuantumCircuit
from qiskit.circuit.library import RepetitionCode
# Note: Full surface code simulation requires Stim (specialized QEC simulator)

# Simplified: distance-3 repetition code
def repetition_code_d3():
    """[[3,1,1]] repetition code — simplest stabiliser code."""
    qc = QuantumCircuit(5, 3)  # 3 data + 2 syndrome qubits
    
    # Encode logical |0⟩ = |000⟩
    # (already initialised to |000⟩)
    
    # Z stabilisers: Z₀Z₁ and Z₁Z₂
    qc.cx(0, 3)   # syndrome qubit 3 measures Z₀Z₁
    qc.cx(1, 3)
    qc.cx(1, 4)   # syndrome qubit 4 measures Z₁Z₂
    qc.cx(2, 4)
    
    qc.measure([3, 4], [0, 1])
    qc.measure(0, 2)  # Decode logical qubit
    return qc

print(repetition_code_d3().draw('text'))

⚛ 5. VQE — Variational Quantum Eigensolver Deep Dive

VQE (Peruzzo et al., 2014) finds the ground state energy of a Hamiltonian using a hybrid quantum-classical loop. It is the workhorse algorithm for NISQ-era quantum chemistry and materials simulation.

5.1 Algorithm Architecture

  1. Hamiltonian mapping: Map the physical Hamiltonian H to qubit Pauli operators via Jordan-Wigner, Bravyi-Kitaev, or Parity mapping
  2. Ansatz construction: Choose a parameterised circuit U(θ) — UCCSD (chemistry), hardware-efficient, or ADAPT-VQE
  3. Expectation estimation: Measure ⟨ψ(θ)|H|ψ(θ)⟩ by decomposing H into Pauli strings and measuring each
  4. Classical optimisation: Update θ using SPSA, COBYLA, L-BFGS-B, or gradient methods (parameter shift rule)
  5. Convergence check: Stop when energy converges to chemical accuracy (1 kcal/mol = 1.6 mHartree)

5.2 Ansatz Strategies

AnsatzTypeCircuit DepthBest For
UCCSDChemistry-motivatedDeep (O(N⁴))Chemical accuracy, small molecules
UCCGSDGeneralised singles+doublesVery deepStrongly correlated systems
Hardware Efficient (HEA)Hardware-nativeShallowNISQ devices, noise tolerance
ADAPT-VQEAdaptive growthCompactOptimal depth for given accuracy
Qubit ADAPT-VQEPauli-based adaptiveVery compactHigh-qubit count problems
 
from qiskit_algorithms import VQE, NumPyMinimumEigensolver
from qiskit_algorithms.optimizers import SPSA, L_BFGS_B, COBYLA
from qiskit.circuit.library import EfficientSU2, TwoLocal
from qiskit.quantum_info import SparsePauliOp
from qiskit.primitives import Estimator
import numpy as np

# Define a simple 2-qubit Ising Hamiltonian: H = -Z₀Z₁ - h(X₀+X₁)
h = 0.5  # Transverse field strength
hamiltonian = SparsePauliOp.from_list([
    ("ZZ", -1.0),   # ZZ interaction
    ("XI", -h),     # Transverse field on qubit 0
    ("IX", -h),     # Transverse field on qubit 1
])
print(f"Hamiltonian: {hamiltonian}")

# Build ansatz: 2-qubit hardware efficient circuit
ansatz = TwoLocal(num_qubits=2, rotation_blocks=['ry', 'rz'],
                   entanglement_blocks='cx', reps=3)
print(f"Ansatz parameters: {ansatz.num_parameters}")

# Run VQE with SPSA optimizer (noise-robust)
estimator = Estimator()
vqe = VQE(
    estimator=estimator,
    ansatz=ansatz,
    optimizer=SPSA(maxiter=300),
    initial_point=np.random.uniform(-np.pi, np.pi, ansatz.num_parameters)
)
result = vqe.compute_minimum_eigenvalue(hamiltonian)

# Classical reference
numpy_solver = NumPyMinimumEigensolver()
exact_result = numpy_solver.compute_minimum_eigenvalue(hamiltonian)

print(f"\nVQE ground state energy:   {result.eigenvalue:.6f}")
print(f"Exact ground state energy: {exact_result.eigenvalue:.6f}")
print(f"Error: {abs(result.eigenvalue - exact_result.eigenvalue)*1000:.3f} mHa")
print(f"Optimal parameters: {result.optimal_point}")

🎯 6. QAOA — Quantum Approximate Optimisation Algorithm

QAOA (Farhi, Goldstone, Gutmann 2014) is a variational algorithm for combinatorial optimisation problems. It alternates between a cost Hamiltonian U_C(γ) (encoding the objective) and a mixer Hamiltonian U_B(β) (exploring the search space).

|ψ(γ,β)⟩ = U_B(βₚ)U_C(γₚ)...U_B(β₁)U_C(γ₁)|+⟩⊗ⁿ

As p→∞, QAOA converges to the exact optimal solution. For p=1, it gives a provable approximation ratio for MAX-CUT: ≥0.6924 (vs best classical algorithm 0.8785 for random 3-regular graphs).

6.1 MAX-CUT with QAOA

import networkx as nx
import numpy as np
from qiskit.circuit.library import QAOAAnsatz
from qiskit.quantum_info import SparsePauliOp
from qiskit_algorithms import QAOA, NumPyMinimumEigensolver
from qiskit_algorithms.optimizers import COBYLA
from qiskit.primitives import Sampler
from qiskit_optimization.applications import Maxcut
from qiskit_optimization.converters import QuadraticProgramToQubo

# Create a 4-node random graph
G = nx.Graph()
G.add_edges_from([(0,1),(0,3),(1,2),(2,3),(1,3)])
print(f"Graph: {G.number_of_nodes()} nodes, {G.number_of_edges()} edges")

# Formulate MAX-CUT as optimisation problem
maxcut = Maxcut(G)
qp = maxcut.to_quadratic_program()
print(f"Objective: {qp.objective}")

# Convert to QUBO (Quadratic Unconstrained Binary Optimisation)
converter = QuadraticProgramToQubo()
qubo = converter.convert(qp)
qubitOp, offset = qubo.to_ising()
print(f"Qubit Hamiltonian: {qubitOp.num_qubits} qubits")

# Solve exactly for reference
numpy_solver = NumPyMinimumEigensolver()
exact_result = numpy_solver.compute_minimum_eigenvalue(qubitOp)
print(f"\nExact MAX-CUT value: {maxcut.interpret(exact_result)}")

# Solve with QAOA (p=2 layers)
sampler = Sampler()
qaoa = QAOA(sampler=sampler, optimizer=COBYLA(maxiter=200), reps=2)
qaoa_result = qaoa.compute_minimum_eigenvalue(qubitOp)
x = maxcut.interpret(qaoa_result)
print(f"QAOA MAX-CUT value: {x}")
print(f"QAOA cut edges: {maxcut.to_quadratic_program().objective.evaluate(x)}")

7.2 Magic State Distillation

Clifford gates are transversal (can be applied fault-tolerantly to code states directly). But T gates are not. Magic state distillation produces high-fidelity "magic states" |T⟩ = (|0⟩+e^(iπ/4)|1⟩)/√2 using noisy T gates and Clifford distillation circuits:

  • Distillation protocol: consume 15 noisy magic states at error p → 1 state at error O(p³)
  • Resource cost: ~1,000:1 ratio of physical to logical magic states
  • This is why fault-tolerant T-gate cost dominates: 1 logical T gate may need ~10,000 physical operations
🔑 Threshold Theorem
If physical error rates are below the fault-tolerance threshold (~1% for surface code), then the logical error rate can be made arbitrarily small by increasing code distance — with only polylogarithmic overhead in computation time. This is the theoretical foundation for scalable quantum computing.

🌐 8. Quantum Networking & the Quantum Internet

8.1 Quantum Network Stack

The quantum internet enables distributed quantum computing, quantum key distribution, and blind quantum computation. It requires a layered architecture analogous to the classical TCP/IP stack:

LayerFunctionKey Technology
PhysicalTransmit qubits over optical fibre / free spaceSingle photon sources, detectors, fibres
LinkGenerate entanglement between adjacent nodesBell state measurements, BSM
NetworkRoute entanglement across multiple hopsQuantum repeaters, entanglement swapping
TransportReliable end-to-end entanglementPurification, entanglement distillation
ApplicationQKD, distributed QC, quantum sensingBB84, E91, teleportation protocols

8.2 Quantum Repeaters

Photons in optical fibre lose ~3 dB per 10 km — classical amplifiers don't work for quantum signals (no-cloning). Quantum repeaters use entanglement swapping and quantum memory to extend range:

  1. Create entanglement between A–B and B–C
  2. Node B performs Bell state measurement on its two halves
  3. This "swaps" entanglement to A–C without transmitting qubits through B
  4. Repeat hierarchically to span continental distances

8.3 Quantum Internet Alliance Milestones

  • Stage 1 (2020–2025): Trusted-node QKD networks (fibre, 100 km range) — Beijing-Shanghai link (2020)
  • Stage 2 (2025–2030): Prepare-and-measure quantum networks with basic entanglement
  • Stage 3 (2030–2035): Few-qubit quantum repeaters, entanglement distribution at scale
  • Stage 4 (2035+): Quantum-memory-enabled repeaters, distributed quantum computing

🔒 9. Quantum Key Distribution & Post-Quantum Cryptography

9.1 BB84 — The First QKD Protocol

BB84 (Bennett & Brassard, 1984) uses quantum mechanics to distribute a secret key with information-theoretic security:

  1. Alice sends random bits encoded in random bases (+/×)
  2. Bob measures in random bases
  3. They publicly announce which bases they used (not the bits)
  4. Keep only bits where they agree on basis → raw key
  5. Any eavesdropping (Eve) disturbs the qubits and is detectable via error rate check
import numpy as np

def simulate_bb84(n_bits=100, noise_level=0.0):
    """Simulate BB84 quantum key distribution protocol."""
    np.random.seed(42)
    
    # Alice: random bits + bases
    alice_bits = np.random.randint(0, 2, n_bits)
    alice_bases = np.random.randint(0, 2, n_bits)  # 0=rectilinear (+), 1=diagonal (×)
    
    # Bob: random bases
    bob_bases = np.random.randint(0, 2, n_bits)
    
    # Transmission (with optional noise / eavesdropping)
    bob_results = np.zeros(n_bits, dtype=int)
    for i in range(n_bits):
        if alice_bases[i] == bob_bases[i]:
            # Same basis → correct measurement
            bob_results[i] = alice_bits[i]
        else:
            # Different basis → random result (quantum mechanics)
            bob_results[i] = np.random.randint(0, 2)
        
        # Add noise (simulates eavesdropping or channel noise)
        if np.random.random() < noise_level:
            bob_results[i] = 1 - bob_results[i]
    
    # Sifting: keep bits where bases match
    matching_bases = alice_bases == bob_bases
    sifted_alice = alice_bits[matching_bases]
    sifted_bob = bob_results[matching_bases]
    
    # Error rate estimation (using a sample subset)
    sample_size = min(20, len(sifted_alice) // 4)
    sample_errors = np.sum(sifted_alice[:sample_size] != sifted_bob[:sample_size])
    qber = sample_errors / sample_size  # Quantum Bit Error Rate
    
    # Final key (remaining after QBER check)
    final_alice = sifted_alice[sample_size:]
    final_bob = sifted_bob[sample_size:]
    
    print(f"BB84 Simulation ({n_bits} bits)")
    print(f"Sifted key length: {len(sifted_alice)} bits")
    print(f"QBER: {qber:.2%}")
    print(f"Final key length: {len(final_alice)} bits")
    print(f"Key match: {np.all(final_alice == final_bob)}")
    
    return final_alice if np.all(final_alice == final_bob) else None

# No eavesdropping
key = simulate_bb84(200, noise_level=0.0)
print(f"\nSecure key: {key[:20]}...")

# With 25% eavesdropping → detectable
print("\n--- With eavesdropping ---")
simulate_bb84(200, noise_level=0.25)

📝 10. Day 4 Quiz & Exercises

Q1. What is the "threshold theorem" in quantum error correction and why is it the theoretical foundation for fault-tolerant computing?
✅ Answer: The threshold theorem states that if the physical error rate of each gate and qubit is below a critical threshold (typically ~1% for the surface code), then by using a quantum error-correcting code with sufficiently large distance d, the logical error rate can be made exponentially small: P_logical ≈ (p/p_th)^(d/2). This means arbitrarily reliable quantum computation is achievable with finite overhead in physical qubits — making scalable quantum computing theoretically possible.
Q2. Why does QAOA with p→∞ give the exact optimal solution, and what is the tradeoff with finite p?
✅ Answer: QAOA with p layers is equivalent to evolving under the Hamiltonian H = γ₁H_C + β₁H_B + ... for p steps. As p→∞ with decreasing step sizes, this becomes the continuous quantum annealing evolution, which reaches the ground state of H_C (the optimal solution) via the adiabatic theorem. For finite p, QAOA gives a sub-optimal approximation — the quality improves with p but circuit depth (and noise on NISQ hardware) increases proportionally. The QAOA tradeoff is expressibility vs circuit depth.
